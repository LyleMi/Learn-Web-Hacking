Risk control
========================================

Common risks
----------------------------------------
- Member
    - Credential stuffing and account theft
    - Account sharing
    - Batch registration
- video
    - Piracy and watching
    - Ad blocking
    - cheating
- Activity
    - Malicious brushing
    - Gathering wool
- live streaming
    - Site popularity
    -Malicious graphics and text
- E-commerce
    - Malicious orders
    - Order fraud
- payment
    - Number theft and card theft
    - money laundering
    - Malicious orders
    - Malicious withdrawals
- other
    - Phishing emails
    - Malicious explosions
    - SMS bombing

defense strategy
----------------------------------------
- Core strategy
    - Same receiving phone number
    - Same shipping address
    - Same historical behavior
    - same IP
    - same device
    - Same payment ID
    - LBS

abnormal characteristics
----------------------------------------
- Abnormal characteristics of APP users
    - IP
    - The device is a specific model
    - There is a sandbox APP in the local APP list
    - Root user
    - Logged into multiple accounts on the same device
