Site information
========================================

- Determine the website operating system
    -Linux case sensitive
    - Windows case insensitivity
- Scan sensitive documents
    - robots.txt
    - crossdomain.xml
    - sitemap.xml
    - xx.tar.gz
    - xx.bak
    - wait
- Determine the language of the website
    - Such as PHP/Java/Python etc.
    - Find the suffix, such as php/asp/jsp
- Front-end framework
    - Such as jQuery/BootStrap/Vue/React/Angular, etc.
    - View source code
- Intermediate server
    - Such as Apache / Nginx / IIS, etc.
    - View the information in the header
    - Judgment based on error message
    - Judge based on the default page
- Web container server
    - Such as Tomcat/Jboss/Weblogic, etc.
- Backend framework
    - Determine based on cookies
    - Judgment based on hash value of resources such as CSS/images
    - Determine based on URL routing
        - Such as wp-admin
    - Judge based on keywords in web pages
    - Based on X-Powered-By in the response header
- CDN information
    - Common ones include Cloudflare and yunjiasu
- Detect whether there is a WAF, and if so, what type
    - If there is a WAF, find a way to bypass it
    - No, go to next step
- Scan sensitive directories for information leaks
    - Before scanning, try a few URLs yourself to see the reaction.
- Use crawlers to crawl website information
- After obtaining certain information, understand the naming ideas of website developers through the obtained directory names, file names and file extensions, determine their naming rules, and infer more directory and file names.
- Common entry goals
    - System with low attention
    - Systems with long business lines
