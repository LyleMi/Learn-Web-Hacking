Shell
================================

Introduction
----------------------------------------
Shell is a special program that is a bridge for users to use Linux. Shell is both a command and a programming language.

Linux contains a variety of Shells, the common ones are:

- Bourne Shell (developed by Bourne at ATT, named sh)
- Bourne Again Shell（/bin/bash）
- C Shell (developed by Bill Joy, named csh)
- K Shell (developed by David G.koun of ATT, named ksh)
- Z Shell (developed by Paul Falstad, called zsh)

Metacharacters
----------------------------------------
Shells generally have a series of special characters used to achieve certain effects. Such characters are called metacharacters (Meta). Different shells may support different metacharacters.

Common metacharacters are as follows:

- ``IFS`` consists of one of <space> or <tab> or <enter>
- ``CR`` is generated by <enter>.
- ``=`` set variables
- ``$`` for variable or operation substitution
- ``>`` redirect stdout
- ``>>`` append to file
- ``<`` redirect stdin
- ``|`` command pipeline
- ``&`` execute commands in the background
- ``;`` Execute the next command after the previous command ends
- ``&&`` executes the next command after the previous command is executed without error.
- ``||`` Execute the next command after an error is reported during the execution of the previous command.
- ``'`` commands within single quotes will retain their original values.
- ``"`` commands within double quotes will allow variable substitution
- `````` The content within the backticks will be executed and replaced as a command
- ``()`` executes commands in a subshell
- ``{}`` executes commands in the current shell
- ``~`` The current user's home directory
- ``!number`` executes historical commands, such as ``!1``

wildcard
----------------------------------------
In addition to metacharacters, wildcard is also a special character in the shell. When the shell encounters a wildcard character in an argument, the shell treats it as a path or file name to search for a possible match on the disk: if a matching match exists, it replaces it, otherwise the wildcard character is passed directly as an ordinary character.

Common wildcards are as follows:

- ``*`` matches 0 or more characters
- ``?`` matches any character
- ``[list]`` matches any character in list
- ``[!list]`` matches any character except list
- ``[a-c]`` matches any character in a-c
- ``{string1,string2,...}`` matches the strings respectively
