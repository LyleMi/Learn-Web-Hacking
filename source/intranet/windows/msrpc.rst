MSPRC
========================================
MSRPC (Microsoft Remote Procedure Call) is Microsoft's modified implementation of the DCE/RPC protocol, which is used to support remote network calls for applications in Windows systems.

The ports used by MSRPC are UDP 135 and TCP 139/445.

MSRPC can be used for

- User traversal
- Service traversal
- Certificate export
- Lateral movement
- Privilege escalation
