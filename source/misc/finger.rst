fingerprint
========================================

browser fingerprint
----------------------------------------
- Software details
    - navigator
    - Install plugins
    - Features supported by the browser
    - CSS support
    - JavaScript features
    - Installed fonts
    - ...
- WebGL information
    - GL version
    - Texture size
    - Render buffer
    - WebGL extension
    - ...
- Hardware information
    - Battery API
    - Sensor API
    - WebRTC gets streaming device
    - System performance
    - ...
- Persistent storage
    - cookie
    - localStorage
    - indexedDB
    - sessionStorage
- System settings
    - Clock offset
- Active detection
    - Construct a specific DNS request and send it
