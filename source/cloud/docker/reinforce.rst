Security hardening
----------------------------------------
- Minimal installation
    - Remove all development tools (compilers, etc.)
- Update system sources
- Enable AppArmor
- Enable SELinux
- Limit the kernel capabilities of running containers
- Remove dependency build
- Configure strict network access control policies
- Start docker without using root user
- Do not run containers in privileged mode
- Control resources
    - CPU Share
    - Number of CPU cores
    - Memory resources
    - IO resources
    - Disk resources
    - Hardware resources
    - The upper limit of the number of processes per unit time
- Use safe base images
- Regular security scans and patch updates
- Remove setuid and setgid permissions in the image
    - ``RUN find / -perm +6000-type f-exec chmod a-s {} \;|| true``
- Configure TLS authentication for Docker daemon
- Disable inter-container communication unless necessary
- rootless Docker
    - https://get.docker.com/rootless
- Use Seccomp to limit syscalls
- Separate build environment and online environment
- Certificate verification
